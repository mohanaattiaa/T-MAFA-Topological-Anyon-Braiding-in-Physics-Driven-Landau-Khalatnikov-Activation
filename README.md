# Topological MAFA (T-MAFA) Phase-Field Activation Layer

An advanced physics-driven machine learning framework that implements a stateful, topologically-protected neural activation layer. The architecture replaces standard static mathematical activations (like ReLU or GeLU) with a dynamic physical system solver that integrates classical **MAFA (Ferroelectric Backbone)** energy land-structures with **Anyon Braid Quantum Modulations**.

The core computation models the **Topological Landau-Khalatnikov (T-LK)** equation solved via a 2D Finite Difference Method (FDM) scheme with stochastic thermal relaxation properties.

## Physics & Architectural Overview

Traditional neural networks lack intrinsic physical boundaries, making them sensitive to adversarial noise. **T-MAFA** forces inputs (acting as virtual electric field tensors E) to undergo physical relaxation across a multi-well thermodynamic landscape containing sub-wells generated by simulated anyon braid frequencies.

### 1. Thermodynamic Energy Landscape
The core engine solves the classical Landau-Ginzburg-Devonshire polynomial expansion augmented with a topological field operator:

∂P/∂t = -(1/γ) * [2αP + 4βP³ + 6νP⁵ - E + κ * ∇_P(W)]

*   **α, β, ν**: Calibrated material constants representing a Lead Zirconate Titanate (PZT) crystal core backbone.
*   **κ**: Topological-Ferroelectric coupling parameter providing structural phase protection.
*   **∇_P(W)**: Trace derivative of the anyon braid word operator, simulated via high-frequency quantum potentials sin(2π * P * W_factor).

### 2. PyTorch Integration Layer
The `TMAFAActivation` module inherits from `torch.nn.Module`. It converts incoming neural activations into boundary conditions for the finite difference mesh, executes a relaxation routine until the system achieves thermodynamic equilibrium, pools the spatial field via a spatial mean operation, and returns a topologically stable output tensor back to the Autograd pipeline.

## Features

*   **Finite Difference Scheme (FDM)**: Fast, vectorized 2D explicit Euler iteration over local polarization matrices P_(x,y).

*   **Thermal Fluctuation Support**: Built-in state initializations incorporating pseudo-thermal fluctuations to emulate system entropy.
*   **Real-time Visualization Engine**: Built-in verification script that generates dynamic state updates across parallel field vectors and tracks spatial matrix grid transitions.

## Quick Start & Usage

### 1. Run Verification & Animation Engine
Execute the script directly to verify the mathematical convergence profile and generate a real-time phase-field relaxation animation:

```bash
python tmafa_engine.py
```

Upon execution, the system will:
1. Initialize 4 parallel mesh matrices experiencing different external field stresses (E ∈ {-1.2, -0.4, 0.4, 1.2}).
2. Save a high-fidelity visualization asset named `animated_tmafa_original_math.gif`.
3. Auto-trigger an environment download payload if executed inside a Google Colab notebook.
4. Pass a test tensor through the `TMAFAActivation` module to demonstrate runtime tensor shape restoration.

### 2. Integration into Custom Neural Architectures
You can drop the `TMAFAActivation` layer directly into standard PyTorch networks just like any other non-linear activation unit:

```python
import torch
import torch.nn as nn
from tmafa_engine import TMAFAActivation

class TopologicallyProtectedMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(784, 128),
            TMAFAActivation(Nx=10, Ny=10, kappa=1.2), # Physical layer
            nn.Linear(128, 10)
        )

    def forward(self, x):
        return self.network(x)
```

## Hyperparameter Reference

When instantiating the `TMAFASolver` or `TMAFAActivation` layers, the physical profile can be tailored using the following parameters:

*   **Nx, Ny** (int, Default: 20, 20): Spatial resolution grid dimensions for the physical finite element mesh.
*   **dt** (float, Default: 0.01): Time integration step size for the explicit Euler discretization solver.
*   **gamma** (float, Default: 1.0): Landau relaxation damping coefficient (viscosity of system).
*   **kappa** (float, Default: 0.8 / 1.2): Coupling strength scaling the quantum braid potential field against the classical core.
*   **temperature** (float, Default: 0.05): Amplitude multiplier tracking randomized initialization thermal noise.
